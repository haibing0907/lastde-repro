## 二、怎么更新数字（两种方式）

### 方式 A：重新生成（推荐，数字不会抄错）

在项目文件夹打开 PowerShell，执行：

```powershell
C:\Users\Administrator\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe make_ppt.py
```

它会重新读 `lastde_results.csv`，生成 `Lastde复现汇报模板.pptx`。
如果该文件正被 PowerPoint 打开，会报 `Permission denied`：先关掉，或者加个文件名参数输出到新文件：

```powershell
C:\Users\Administrator\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe make_ppt.py "Lastde复现汇报模板_v2.pptx"
```

> 注意：这会覆盖你手动改过的内容。建议“先跑数据，最后再生成 PPT”。

### 方式 B：手动改

第 11、12、13、15 页的数字都是普通文本框，双击就能改。

## 三、第 14 页怎么填（三组待补实验）

| 卡片 | 跑什么 | 填什么 |
|---|---|---|
| 跨数据集 | `--data reddit_gpt2_xl`、`--data squad_gpt2_xl` | 两组 AUROC |
| 代理模型规模 | `--model distilgpt2 / gpt2 / gpt2-medium` | 三个 AUROC + MDE 是否恢复 |
| 文本长度 | `--max-tokens 64 / 128 / 256` | 三组 AUROC |

每组跑完把数字填进对应卡片的【待填】。如果时间只够做一组，优先做**代理模型规模**——它和第 15 页的“MDE 反转”直接呼应。
